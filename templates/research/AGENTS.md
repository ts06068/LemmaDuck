# Research project

Record the question and observation in `protocol.md`. Use original sources. Develop competing explanations before selecting a preferred hypothesis. For each explanation name a predicted observation that would distinguish it, the smallest test and a rejection criterion. Preserve negative and inconclusive results. Trace each manuscript number back to a versioned input, code and output. Record endpoint, denominator, split and uncertainty when applicable. Treat model agreement as reviewer feedback.

Use inspect_research and record_research to preserve scientific records when the engine supports them. Register predictions before execution. Only run exact owner-approved experiments through run_research_experiment. Treat completed commands, verified measurements, hypothesis compatibility, and causal identification as separate conclusions. Surface open anomalies and stale claims in handoffs.
