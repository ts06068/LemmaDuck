The exact-label rubric penalizes all six timing answers for mentioning possible unmeasured confounding. That warning is defensible when qualified; an added issue code does not prove the bias exists. The original automated scores remain unchanged. The extra time_zero label in R21 is largely redundant. Conversely, R05 contains an actionable wording problem that the automatic code-based scorer missed. The persona review therefore audits the rubric as well as the answers. It is not an independent test that establishes a winner.

The no-overlap case already supplies the answer to the selected next check. A future, separately frozen benchmark should score genuinely discriminating next actions, permit qualified secondary concerns, and require explicit patient-disjoint split instructions. Do not tune prompts on these cases and call their reuse fresh validation.

The review uses time-zero alignment as discussed by [Hernán et al.](https://pmc.ncbi.nlm.nih.gov/articles/PMC5124536/). The site-separated example concerns the lack of support for conventional adjustment, consistent with [Westreich and Cole](https://pmc.ncbi.nlm.nih.gov/articles/PMC2877454/); stronger substantive extrapolation assumptions would be additional assumptions, not evidence supplied by model depth. The prediction review checks illegitimate future features and dependent train/test groups, drawing on [Kapoor and Narayanan](https://pmc.ncbi.nlm.nih.gov/articles/PMC10499856/).
